# 자산 배분 자동화 프로그램 매뉴얼 (Ver 2.0)

## 1. 프로젝트 개요
본 프로젝트는 검증된 정량적 투자 전략(ODM, VAA, LAA, BAA)을 기반으로 자산 배분을 자동화하고, 백테스트를 통해 최적의 포트폴리오를 도출하는 프로그램입니다.
최신 업데이트를 통해 **Protocol 20**이라는 고도화된 전략을 탑재하였으며, 시장 상황(VIX, 금리)에 따라 유연하게 대응하는 로직을 포함하고 있습니다.

## 2. 프로젝트 구조
```
asset_allocation/
├── main.py                  # [실전] 매매용 메인 프로그램 (현재 포트폴리오 계산)
├── backtest.py              # [테스트] 기본 백테스트 (BAA+LAA 등 비중 조절 가능)
├── backtest_protocol20.py   # [테스트] Protocol 20 전용 백테스트 (VIX, Smart Bond 튜닝)
├── backtest_advanced.py     # [테스트] 고급 기능 실험 (중간 손절, 동적 비중 조절)
├── strategies/              # 전략 로직 폴더
│   ├── baa_strategy.py      # BAA-G4 (Leverage)
│   ├── laa_strategy.py      # LAA (Smart Bond 포함)
│   ├── protocol20_strategy.py # Protocol 20 (VIX Gate 포함)
│   └── ...
├── utils/                   # 유틸리티 폴더
│   ├── tiingo_utils.py      # 데이터 수집 (API + DB 캐싱)
│   └── db_utils.py          # SQLite DB 관리
└── market_data.db           # 로컬 데이터베이스 (자동 생성)
```

## 3. 주요 투자 전략

### 3.1 BAA + LAA (추천: 안정형)
*   **개념**: 공격적인 BAA와 수비적인 LAA를 혼합하여 수익과 안정성의 균형을 맞춘 전략.
*   **구성**: BAA 40% + LAA 60% (또는 50:50)
*   **특징**:
    *   **BAA**: 카나리아 신호로 하락장을 피하고, 상승장엔 레버리지(2배)로 수익 극대화.
    *   **LAA**: 영구 포트폴리오 기반으로 계좌의 변동성을 잡아줌.
*   **성과 (2010~2026)**: CAGR 약 11~12%, MDD -17% 수준.

### 3.2 Protocol 20 (추천: 성장형)
*   **개념**: 연수익률 20% 달성을 목표로 설계된 고수익 추구 전략.
*   **구성**: Protocol 20 (80%) + LAA (20%)
*   **핵심 로직**:
    1.  **Volatility Gate**: VIX 지수가 특정 값(예: 30) 이상이면 레버리지 사용 중단 (1배수로 전환).
    2.  **Smart Bond**: 금리 상승기(10년물 금리 > 10개월 이동평균)에는 채권(IEF) 대신 현금(BIL) 보유.
*   **성과 (2010~2026)**: CAGR 약 15%, MDD -20% 수준.

## 4. 실행 방법

### 4.1 실전 매매 (포트폴리오 추출)
오늘 날짜 기준으로 어떤 종목을 얼마나 사야 하는지 계산합니다.
```sh
python main.py
```
*   실행 후 초기 투자금을 입력하면 `result/` 폴더에 엑셀 파일이 생성됩니다.

### 4.2 백테스트 (전략 검증)

**A. 기본 테스트 (BAA+LAA 비중 조절)**
```sh
python backtest.py
```
*   파일 상단의 `BAA_WEIGHT` 변수를 수정하여 비중을 조절할 수 있습니다.

**B. Protocol 20 테스트 (VIX, 금리 로직 튜닝)**
```sh
python backtest_protocol20.py
```
*   파일 상단의 `VIX_THRESHOLD`, `USE_SMART_BOND` 변수를 수정하여 튜닝할 수 있습니다.

**C. 고급 기능 테스트 (손절, 동적 비중)**
```sh
python backtest_advanced.py
```
*   중간 손절(-5%)이나 동적 비중 조절 로직의 효과를 비교 분석합니다.

## 5. 데이터 관리 (API & DB)
*   **스마트 캐싱**: 최초 실행 시에만 API(Tiingo, FRED)를 호출하여 데이터를 `market_data.db`에 저장합니다. 이후에는 DB에서 데이터를 불러오므로 속도가 빠르고 API 사용량을 아낄 수 있습니다.
*   **자동 업데이트**: DB에 저장된 데이터가 최신이 아니면(어제 날짜 이전), 자동으로 부족한 부분만 API로 받아와 업데이트합니다.

## 6. 투자 인사이트
*   **수익 vs 위험**: 수익률(CAGR)을 1% 높이려면 위험(MDD)도 약 1% 감수해야 합니다. 본인의 성향에 맞는 전략을 선택하세요.
*   **채권의 배신 대비**: 'Smart Bond' 로직은 2022년과 같은 금리 급등기에 계좌를 방어하는 데 매우 효과적입니다.
*   **장기 투자**: 어떤 전략이든 최소 3~5년 이상 유지해야 통계적 우위를 누릴 수 있습니다.
