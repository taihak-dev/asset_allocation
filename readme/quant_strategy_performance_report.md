# 퀀트 전략 검증 및 성과 분석 보고서

**작성일**: 2026년 1월 17일  
**작성자**: Asset Allocation AI Assistant

---

## 1. 백테스트 개요 (Overview)

본 프로젝트는 과거의 시장 데이터를 기반으로 다양한 자산 배분 전략을 시뮬레이션하여, 미래의 불확실한 시장에서도 **안정적인 수익(Alpha)**을 창출할 수 있는 최적의 투자 모델을 찾기 위해 수행되었습니다.

*   **테스트 기간**: 2010년 1월 1일 ~ 2026년 1월 16일 (약 16년)
*   **초기 투자금**: $10,000 (달러)
*   **데이터 출처**: Tiingo (주가 데이터), FRED (거시 경제 데이터 - 실업률, 금리, VIX)
*   **검증 방식**: 월간 리밸런싱 (매월 첫 영업일 기준), 거래 비용 및 슬리피지는 미반영.

## 2. 테스트 목적 (Purpose)

1.  **수익률 제고**: 기존의 정적 자산 배분(60/40 등)을 넘어서는 **연복리수익률(CAGR) 10% ~ 20%** 달성.
2.  **위험 관리**: 2008년 금융위기나 2022년 인플레이션 쇼크와 같은 하락장에서 **최대 낙폭(MDD)을 -20% 이내**로 방어.
3.  **전략 고도화**: 단순한 모멘텀 전략을 넘어, 거시 경제 지표(금리, 공포 지수)를 활용한 **'Protocol 20'** 신규 전략의 유효성 검증.

## 3. 사용된 전략 분석 (Strategies)

이번 테스트에서는 총 4가지 핵심 전략과 이를 조합한 하이브리드 모델을 검증했습니다.

| 전략명 | 성격 | 장점 (Pros) | 단점 (Cons) |
| :--- | :--- | :--- | :--- |
| **ODM** (Original Dual Momentum) | 추세 추종 | 로직이 단순하고 큰 하락장을 잘 피함. | 반응 속도가 느려(12개월) 급반등 장세에서 소외됨. |
| **VAA** (Vigilant Asset Allocation) | 초고속 방어 | 방어력이 매우 뛰어남 (MDD 한 자릿수 가능). | 잦은 매매로 인한 피로도, 횡보장에서 손실 누적(Whipsaw). |
| **LAA** (Lethargic Asset Allocation) | **수비수 (Anchor)** | 영구 포트폴리오 기반으로 매우 안정적임. | 수익률이 낮아 자산 증식 속도가 느림. |
| **BAA** (Bold Asset Allocation) | **공격수 (Engine)** | 카나리아 신호로 위험을 감지하고, 레버리지(2배)로 수익 극대화. | 공격적인 만큼 변동성이 큼. |
| **Protocol 20** (New) | **지능형 공격수** | BAA 기반에 **VIX(공포지수)**와 **금리(Smart Bond)** 필터를 장착. | 로직이 다소 복잡하며, 파라미터(VIX 기준 등) 튜닝이 필요함. |

## 4. 시나리오별 테스트 결과 (Results)

다양한 전략 조합을 테스트한 결과, 유의미한 성과를 보인 상위 3개 시나리오는 다음과 같습니다.

### 🥉 Case 1: 4개 전략 혼합 (ODM+VAA+LAA+BAA)
*   **구성**: 4개 전략에 자산을 25%씩 균등 배분.
*   **CAGR (수익률)**: **9.89%**
*   **MDD (최대낙폭)**: **-16.89%**
*   **평가**: 너무 많은 전략을 섞다 보니 서로의 장점이 상쇄되어 수익률이 평범해짐. (탈락)

### 🥇 Case 2: 안정형 조합 (BAA 40% + LAA 60%)
*   **구성**: 공격수(BAA)와 수비수(LAA)의 황금 비율.
*   **CAGR (수익률)**: **11.01%**
*   **MDD (최대낙폭)**: **-16.90%**
*   **평가**: **"가장 마음 편한 투자"**. 수익률도 준수하고(시장 평균 상회), 어떤 위기가 와도 계좌가 크게 망가지지 않음.

### 🥈 Case 3: 성장형 조합 (Protocol 20)
*   **구성**: P20(80%) + LAA(20%) / **VIX 기준 30** / **Smart Bond 적용**
*   **CAGR (수익률)**: **15.01%**
*   **MDD (최대낙폭)**: **-20.52%**
*   **평가**: **"자산 증식의 치트키"**. 수익률이 압도적으로 높음. 단, MDD가 -20%를 살짝 넘기므로 투자자의 담력이 필요함.

## 5. 핵심 발견 (Key Insights)

1.  **VIX의 역설**: 공포 지수(VIX)가 높다고 무조건 피하는 것은 정답이 아니었습니다. VIX 기준을 20에서 30으로 완화했을 때, 오히려 상승장의 수익을 온전히 챙길 수 있었습니다.
2.  **채권은 더 이상 안전하지 않다**: 2022년 금리 급등기에 채권도 주식만큼 하락했습니다. 이를 방어하기 위해 도입한 **'Smart Bond(금리 상승 시 현금화)'** 로직은 MDD를 줄이는 데 결정적인 역할을 했습니다.
3.  **수익과 위험의 교환**: 연수익률 15%를 얻으려면 -20%의 하락을 견뎌야 하고, -17%까지만 견디고 싶다면 수익률은 11%로 낮아집니다. 이는 금융 시장의 불변의 법칙입니다.

## 6. 최종 결론 (Conclusion)

사용자의 투자 성향에 따라 두 가지 최적의 선택지를 도출했습니다.

*   **선택 A (안정 추구형)**: **BAA(40%) + LAA(60%)**
    *   은퇴 자금이나 절대 잃으면 안 되는 목돈을 운용할 때 적합합니다.
*   **선택 B (수익 추구형)**: **Protocol 20 (VIX 30, Smart Bond On)**
    *   10년 이상 장기 투자가 가능하고, 변동성을 즐길 수 있는 투자자에게 적합합니다.

본 프로젝트는 위 두 가지 전략을 모두 수행할 수 있도록 시스템이 구축되었습니다.
